# Gymwear Store App

A multi-store gymwear e-commerce app built with Expo and React Native. One codebase serves two branded storefronts, **FitWear** ("Train hard. Live strong.") and **UrbanFit** ("Effortless athleisure & streetwear"). You can switch between them at runtime, and each store has its own theme, catalog, banners, loyalty program and feature flags.

## Features

- **Multi-store white-labeling**: each store is defined by a config in `src/config/stores/` that sets its colors, branding, banners, loyalty tiers and features.
- **Store switcher**: change the active store in the app. The cart and wishlist are kept separately for each store.
- **Catalog**: home feed (featured, new arrivals, best sellers), category collections, filtering (category, price, size, in stock) and sorting.
- **Product details**: image gallery, size and color variant selector, size guide, reviews and related products.
- **Search** across title, description, category and tags.
- **Cart and wishlist** saved on the device with AsyncStorage.
- **Onboarding** welcome screen, shown on first launch only.
- **Loyalty program** banner and tiers, set per store.

## Getting started

### Prerequisites

- Node.js (LTS) and Yarn 1.x
- Xcode and CocoaPods, for iOS
- Android Studio with an emulator, for Android

### Install

```bash
yarn install
```

### Run

```bash
yarn start      # start the Expo dev server
yarn ios        # build and run on the iOS simulator  (expo run:ios)
yarn android    # build and run on an Android emulator (expo run:android)
yarn web        # run in the browser
```

The `ios/` and `android/` folders are generated by Expo prebuild. Change native settings in `app.json` or a config plugin, not in those folders.

### Checks

```bash
npx tsc --noEmit   # typecheck
npx expo lint      # lint
npx expo-doctor    # check dependencies and config
```

Add new packages with `npx expo install <package>` so you get versions that work with SDK 58.

## Data layer

The app reads mock data from `src/data/`. `ProductService` adds a short delay to each call so loading states and TanStack Query caching behave as they would against a real API.

`src/services/shopify/ShopifyStorefrontAdapter.ts` is a ready-made Shopify Storefront GraphQL client. It handles products, product lookup by handle, and cart create, add, update and remove, and it maps Shopify data to the app's `Product` type. It is not wired into the screens yet. To use a live store, create an adapter with your store domain and Storefront access token, then call it from the service layer instead of the mock data:

```ts
import { ShopifyStorefrontAdapter } from './src/services/shopify';

const shopify = new ShopifyStorefrontAdapter({
  storeDomain: 'your-store.myshopify.com',
  storefrontAccessToken: '<token>',
});
```

## Adding a new store

1. Create `src/config/stores/<id>.config.ts` that exports a `StoreConfig` (theme, branding, banners, loyalty, features).
2. Add the id to the `StoreId` union in `src/types/store.ts`.
3. Register the config in `STORE_CONFIGS` in `src/config/stores/index.ts`.
4. Add the store's products in `src/data/products/` and register them in `STORE_PRODUCTS_MAP`.
